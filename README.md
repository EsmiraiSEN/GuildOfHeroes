## Собственный проект

Тема проекта: библиотека

Главный класс: Book

Почему этот объект нужен программе:
Book описывает одну книгу библиотечного фонда: название, автора, год издания,
количество страниц и доступность для выдачи. Без класса пришлось бы заводить
отдельные переменные для каждой книги, и они быстро запутались бы

Какие данные хранит объект:

- Title — название книги
- Author — автор
- Year — год издания
- Pages — количество страниц
- IsAvailable — доступна ли книга для выдачи

Какие значения задаются через конструктор:
Title, Author, Year, Pages — они уникальны для каждой книги

Какие значения можно задавать автоматически:
IsAvailable = true — новая книга доступна для выдачи

Какое значение я решила задавать автоматически и почему?
IsAvailable = false, потому что при добавлении книги в фонд она выдана, и это значение не нужно передавать при каждом создании объекта

### Самостоятельный шаг (ПР №2)

## Практическая работа №3

### Защита состояния Hero
- Прямая запись в поле обходила методы, потому что поле было `public`. Теперь свойства имеют `private set`, и снаружи можно только читать.
- Начальное здоровье проверяется в конструкторе (ограничивается от 0 до 200).
- `Heal` сохраняет границу `MaxHealth`, вычисляя `missingHealth`.
- Свойство `Name` использует поле `_name` и `value.Trim()`, чтобы убирать пробелы. В конструкторе `Name = name;` вызывает этот сеттер.

### Проверки
- Конструктор: `-100` дал `0/100`, `5000` дал `200/200`.
- Имя: `"   Александр   "` превратилось в `"Александр"`.
- Запись `alexander.Health = -100;` вызвала ошибку CS0272 (сеттер закрыт).

### Исправление ошибок
1. Ошибка: `public int Health { get; set; }`. Исправление: добавить `private` перед `set`. Проверка: запись снаружи не компилируется.
2. Ошибка: `value.Trim(); _name = value;`. Исправление: `_name = value.Trim();`. Проверка: имя выводится без пробелов.
