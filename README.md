## Собственный проект

Тема проекта: библиотека

Главный класс: Book

Почему этот объект нужен программе:
Book описывает одну книгу библиотечного фонда: название, автора, год издания,
количество страниц и доступность для выдачи. Без класса пришлось бы заводить
отдельные переменные для каждой книги, и они быстро запутались бы

Какие данные хранит объект:

- Title — название книги
- Author — автор
- Year — год издания
- Pages — количество страниц
- IsAvailable — доступна ли книга для выдачи

Какие значения задаются через конструктор:
Title, Author, Year, Pages — они уникальны для каждой книги

Какие значения можно задавать автоматически:
IsAvailable = true — новая книга доступна для выдачи

Какое значение я решила задавать автоматически и почему?
IsAvailable = false, потому что при добавлении книги в фонд она выдана, и это значение не нужно передавать при каждом создании объекта
